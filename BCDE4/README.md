## The system (Russell, cumulative universes; bcde.pdf App. B)
* `U_l : U_m` for `l < m` (`LtL`: `l⁺ ∨ m = m`), cumulativity `A : U_l, l ⩽ m ⇒ A : U_m`
  (`ty-cum`, `conv-cum`), `Π A B : U_l` for `A, B : U_l`, `∅ : U_l`;
  `U_l = U_l' : U_m` for `l = l'` (`conv-U-lvl`, invariance under level equality);
* a separate type judgement `IsType`: `A : U_l ⇒ A type`, Π of types, and the
  LARGE types `[α]A` (`is-LPi`) and `[ψ]A` (`is-Grd`), which live in no universe
  (as in the paper); guard β and ψ-equivalence are type conversions
  (`conv-Ty-Grd-beta`, `conv-Ty-Grd-equiv`);
* levels `α_i | l ∨ m | l⁺` as de Bruijn level variables; constraints `l = m`;
  a context carries a level theory (`lctx`), extended by `addC` (constraint)
  and `addL` (a new level variable, shifting everything);
* Π/λ/app, `[ψ]A` / `⟨ψ⟩t` with β when ψ valid, `∅` + collapse in loopy contexts;
* level products `[α]A` (`LPi`), `⟨α⟩u` (`LLam`), `t l` (`LApp`) with
  congruences, β (`(⟨α⟩u) l = u[l/α]`) and η.
* **invariance under level equality** (bcde.pdf): `conv-cong-LApp-lvl`
  (`t l = t l'` for `l = l'` valid; the instance conversion `A[l] = A[l']` is a
  premise, like `conv-cong-App-arg`), `conv-Grd-equiv` / `conv-GLam-equiv`
  (`[ψ]A = [ψ']A`, `⟨ψ⟩t = ⟨ψ'⟩t : [ψ]A` for `ψ ⇔ ψ'`, `Levels.EquivC`).
* `RussellLeq`: **level-equality lemma** — `z, z'` pointwise equal in the target
  constraints give `Δ ⊢ Mz = Mz' : Az` (`leq-HasType`, structural, like
  `RussellMetaCong`); corollaries `lsub1-cong` (`A[l] = A[l']`) and
  `mk-conv-cong-LApp-lvl` (the rule with the paper's premises only).
* `RussellLsub`: **level-substitution lemma** for all judgement forms
  (`lsubD-*`), along any `z : LSub` that maps the constraints to valid ones
  (`LSubOK`); `lsubCtx-inst` / `lsub1-liftL` relate the body under `liftL z`
  instantiated at `l` with the body at `l·z`.

## The model
* `U_l` is interpreted by the universe code of the canonical code of `l`
  (`EvalRel (U l) ρ = ↓ UCode (lcode (θ l))`); membership in the model ignores
  the universe code, so cumulativity is free and `A : U_l` means `A` type;
* the relation's universe clause remembers the level (`Valid.Stratified.RValU`:
  `M ⇒ U_l` with `code l = k`), which gives U-injectivity;
* new codes `LevTy`, `LevEl k`, `LPiCode f` (≈ `PiCode LevTy f`), `Dom/*`;
* level expressions are coded by `D : LDecAll` = for every level theory T a
  canonical code `lcode : LExpr → Nat` with `lcode l = lcode m ⇔ Valid T l m`
  and a decoding `ldec` (`Levels.LDec`);
* `⟦[α]A⟧ρ ∋ LPiCode f` iff every edge `(LevEl k ↦ v)` of `f` is a value of
  `A` at the level `ldec k`, with a canonicity witness `lcode (ldec k) = k`
  (strict witness form `LBody`; Bot-valued edges are free);
* the relation records for `[α]A` carry level-VARIATION fields, the analogues of
  Π's `edgeE`/`appE`: `RValTyLPi.edgeLE` (`A[l] ~ A[l']`) and `RValLPi.appLE`
  (`t l ~ t l'`) for `l = l'` valid in the context;
* guards evaluated in the ambient theory of the TARGET context (a level-erasing
  model is unsound with collapse — see `BCDE/CollapseTest`).

## Adequacy (`Adeq/`)
* `Adeq/Level.agda` (`[α]A`, `⟨α⟩u`) and `Adeq/LevelApp.agda` (`t l`, β, η): the
  combinators take the IH at EVERY instance `A[l/α]`
  (`(l : LExpr) → AdqTy G (lsub1 A l)`), also for application (to transport the
  value along a Sup, as `App.agda` uses `AdqTy (Γ.A) B`).
* `Adeq/Driver.agda`: structural induction on derivations, each statement
  proved for all level substitutions z (`adqTm d z : Adq Gz Mz Az`), so the
  binder cases call the IH at `l·z`; the semantic cases are
  substitution-free combinators, the driver only transports along the
  `RussellLsub` equations.  `adqTm0`, … are the identity instances.
* level variation (`adqLv d z z' : AdqE1 K Mz Mz' Az` for `z = z'` pointwise in
  `lctx K`) is a fifth mutual statement, proved like `RussellLeq` with the
  congruence combinators; it feeds the new fields through the hypotheses
  `LvTy G A = (l l') → AdqETy (Γ, l = l') A[l] A[l']` (and `LvTm`), used in a
  target validating `l = l'` exactly as the guard cases use `Γ,ψ`
  (`Adeq/Level.agda`).  `Adeq/Relevel.agda`: the statements survive
  strengthening the constraints of the context.

## Loop checking (`LC/`, Bezem–Coquand, loopalg1.pdf)
* `Horn`: level theory ↦ Horn clauses over atoms `x + k`; forward derivability `Der`.
* `Equiv`: Theorem 2.2 — `Valid T l m` ⇔ derivability of the atoms both ways.
* `Iter`: capped forward iteration to a least capped fixpoint (invariants `Inv`).
* `Cert`: loop certificate — a value gap `(t, t+MaxG]` above the start separates
  a set W whose atoms are then ALL derivable (shift invariance).
* `Decide`: outer recursion on the number of finite variables ⇒
  `decValid : Either (Valid T l m) ¬(Valid T l m)`;
  `Codes` + `ldecAll : LDecAll` (least index in an enumeration of LExpr).
* `LC/Test`: closed tests by `refl` (valid/invalid, and a loop certificate).
