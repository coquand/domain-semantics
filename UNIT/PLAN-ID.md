hierarchy at every level bound N:

- T_Tarski ↔ T_E, the Ehrhard GAT (Theorems 16, 20);

   Lemma 18 or of uniqueness needs a principle not available; the Id-code

## 3. The design (fix details in the design note, I0)

Use based J (Paulin-Mohring), as in `CwFId`. For A a type, a : A, and a
motive C over Γ.A.Id(A p, a p, q):

    J(A, a, C, d, b, e) : C[b, e]    for d : C[a, refl(A, a)], b : A, e : Id(A, a, b)
    J(A, a, C, d, a, refl(A, a)) = d                (strict β)

Keep all annotations: refl(A, a), and J carries A, a, C. Then Lemma 25
needs no injectivity of Id, just as the annotations on λ and app make
injectivity of Π unnecessary.

- **T_Tarski** (de Bruijn, implicit substitution):
  - types `id A a b`; terms `refl A a`, `jj A a C d b e`;
  - codes `idc n a x y : U_n` with `el n (idc n a x y) = id (el n a) x y`;
  - `lf m n (idc m a x y) = idc n (lf m n a) x y`;
  - congruences; β.
- **T_Russell:**
  - `id A a b`, `refl A a`, `jj A a C d b e`;
  - universe rule: A : U_n, a b : A ⇒ id A a b : U_n;
  - cumulativity as before.
- **T_E** (explicit substitutions):
  - the same formers;
  - naturality: Id(A,a,b)σ = Id(Aσ,aσ,bσ), refl(A,a)σ = refl(Aσ,aσ), and

        J(A,a,C,d,b,e)σ = J(Aσ, aσ, C lift(lift_A σ), dσ, bσ, eσ)

    where the inner lift is over Id(A p, a p, q) and its type needs the
    conversion Id(A p, a p, q) lift_A(σ) = Id(Aσ p, aσ p, q);
  - codes and Tarski equations as above.
- **Erasures:**
  - Tarski erasure of T_E maps the formers homomorphically;
  - Russell erasure: |idc n a x y|_R = id |a|_R |x|_R |y|_R, and the
    others homomorphically.

## 4. Plan for stage 1

- **I0. Design note** (`PLAN-ID-I0.md`; write it first, no need to wait
  for the user).
  Write out the exact new raw constructors and every new rule in all three
  systems (formation, introduction, β, congruences, naturality in T_E,
  codes, decoding, lift equations), with their premises in the style of
  the existing rules (presupposition premises as in §6 of the tex). Also
  state the inversion facts I3 must prove, and how Id, refl and J are
  interpreted in the filter model.
- **I1. Syntax and rules.** Extend the raw syntax and rules in
  `TSyntax`, `TTyping`, `RTyping`, `GAT`. Then fix every `split` in the
  cone up to and including stage 1. Grep for `split` over `Tm`, `GE`,
  `Der`, `RDer`, `GDer` in the files below.
- **I2. Syntactic lemmas.** `TSubst`, `TSubCong`, `TSubLib` (renaming,
  substitution, Lemma 15); `TPresup`, `TLean`; `GPresup`, `GLean`;
  `RLevels`, `ErR` (Lemma 21, erasure commutes with substitution).
- **I3. Inversion (the risk).**
  - Extend the filter model: `LTypes` (the domain; add an Id constructor
    to `Ty`, e.g. `idt s`, or whatever the design note fixes),
    `LConsistency`, `LTyping`, `LFilter`, `LSoundF`, `TSem`, `TSound`,
    `TRed`.
  - Then extend `TInv` with the no-confusion facts needed later:
    - Id ≠ Π, Id ≠ U_n, Π ≠ U_n (existing);
    - injectivity of levels (existing);
    - and for codes: idc vs pic vs uc pairwise distinct, uc injective
      (existing).
  - Soundness of the β rule of J is the point to watch: refl and J need
    continuous interpretations with J(…, d, …, refl) = d. One candidate:
    J returns d when the proof is at least refl, ⊥ otherwise.
  - Record in the log whether consistency still holds. If it fails, that
    is a stop condition.
- **Acceptance for stage 1.** A driver `IdCheck.seg` in the worktree
  imports the cone through `TInv` plus `RTyping`, `RLevels`, `ErR`, `GAT`,
  `GPresup`, `GLean`, `GSound`. It checks with 0 failures, and a
  deliberate error is rejected in each changed file. The later files (Ev,
  L18*, L19, Thm20, TGen, TUniq*, TSection, RGAT, the A*/F*/C* files,
  semantics) will not check yet on the branch; that is expected.
