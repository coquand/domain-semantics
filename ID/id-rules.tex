\noindent
This note records the rules for the element-level Martin-L\"of identity type
added to the type-in-type theory ($\U:\U$) of the \texttt{ID/} development, and
states the two metatheorems proved for it. Everything below is machine-checked
in Agda (\texttt{-{}-without-K -{}-exact-split}) with no postulates, no holes,
and no termination/positivity pragmas.

\medskip
\noindent
The eliminator is Martin-L\"of's \emph{original} $\Jelim$ with a
fully dependent motive. Writing the motive and base types out,
\[
  C : (x\,y:A)\to \Id\,A\,x\,y \to \U,
  \qquad
  d : (x:A)\to C\,x\,x\,(\Rf\,x),
\]
so that $\Jelim\,C\,d\,p$ at $p:\Id\,A\,a\,b$ has type $C\,a\,b\,p$ (the
application spine $((C\,a)\,b)\,p$).

\section*{Typing rules}

\begin{mathpar}
\inferrule[Id]{\ty{\Ga}{A}{\U} \\ \ty{\Ga}{a}{A} \\ \ty{\Ga}{b}{A}}
  {\ty{\Ga}{\Id\,A\,a\,b}{\U}}
\and
\inferrule[Ref]{\ty{\Ga}{A}{\U} \\ \ty{\Ga}{a}{A}}
  {\ty{\Ga}{\Rf\,a}{\Id\,A\,a\,a}}
\end{mathpar}

\begin{mathpar}
\inferrule[J]{
  \ty{\Ga}{A}{\U} \\ \ty{\Ga}{a}{A} \\ \ty{\Ga}{b}{A} \\\\
  \ty{\Ga}{C}{(x\,y:A)\to \Id\,A\,x\,y\to\U} \\
  \ty{\Ga}{d}{(x:A)\to C\,x\,x\,(\Rf\,x)} \\
  \ty{\Ga}{p}{\Id\,A\,a\,b}}
  {\ty{\Ga}{\Jelim\,C\,d\,p}{C\,a\,b\,p}}
\end{mathpar}

\section*{Conversion rules}

\begin{mathpar}
\inferrule[J-$\beta$]{
  \ty{\Ga}{A}{\U} \\ \ty{\Ga}{a_0}{A} \\
  \ty{\Ga}{C}{\dots} \\ \ty{\Ga}{d}{\dots}}
  {\cv{\Ga}{\Jelim\,C\,d\,(\Rf\,a_0)}{d\,a_0}{C\,a_0\,a_0\,(\Rf\,a_0)}}
\end{mathpar}

\noindent
$\Jelim$ fires only on a \emph{literal} $\Rf\,a_0$, whose type is the diagonal
$\Id\,A\,a_0\,a_0$; both sides of J-$\beta$ therefore have the \emph{same} type
$C\,a_0\,a_0\,(\Rf\,a_0)$, so the rule carries no endpoint or motive equalities
and needs no injectivity. The congruences are

\begin{mathpar}
\inferrule[Id-cong]{
  \cv{\Ga}{A}{A'}{\U} \\ \cv{\Ga}{a}{a'}{A} \\ \cv{\Ga}{b}{b'}{A}}
  {\cv{\Ga}{\Id\,A\,a\,b}{\Id\,A'\,a'\,b'}{\U}}
\and
\inferrule[Ref-cong]{\cv{\Ga}{a}{a'}{A}}
  {\cv{\Ga}{\Rf\,a}{\Rf\,a'}{\Id\,A\,a\,a}}
\end{mathpar}

\begin{mathpar}
\inferrule[J-cong]{
  \cv{\Ga}{C}{C'}{\dots} \\ \cv{\Ga}{d}{d'}{\dots} \\ \cv{\Ga}{p}{p'}{\Id\,A\,a\,b}}
  {\cv{\Ga}{\Jelim\,C\,d\,p}{\Jelim\,C'\,d'\,p'}{C\,a\,b\,p}}
\end{mathpar}

\noindent
(Grey premises re-typing the components are elided; see
\texttt{ID/Syntax/Typing.agda}.)

\section*{Head reduction}

Reduction is untyped weak head reduction. The single-step relation
$M \redone N$ has the following $\Id$-clauses (alongside the usual
$\beta$ and application-congruence for functions):

\begin{mathpar}
\inferrule[J-red]{ }{\Jelim\,C\,d\,(\Rf\,a) \;\redone\; d\,a}
\and
\inferrule[J-scrut]{p \redone p'}{\Jelim\,C\,d\,p \;\redone\; \Jelim\,C\,d\,p'}
\end{mathpar}

\noindent
\textsc{J-red} is the $\iota$-step; \textsc{J-scrut} lets reduction proceed into
the proof position so a non-canonical proof can reduce toward a $\Rf$. Each step
is a typed conversion (\textsc{J-red} $\mapsto$ J-$\beta$, \textsc{J-scrut}
$\mapsto$ J-cong), and $\redone$ is deterministic.

\section*{Domain semantics of $\Id$ and $\Jelim$}

The model is the poset of \emph{finite elements} $u,v,w,\dots$ of a Scott
domain, with an information order $u\le v$, a bottom $\bot$, a universe code
$\bU$, function elements, and $\Pi$-codes. The identity type adds two shapes:
\[
  \cId(t,u,v) \quad\text{(the \emph{code} of a type $\Id\,A\,a\,b$: $t$ codes
  $A$, $u$ the value of $a$, $v$ the value of $b$),}
\]
\[
  \rEl(w) \quad\text{(a \emph{proof value}: a witness $w$, the model's analogue
  of $\lambda$ for functions).}
\]
Semantic membership is written $\mem{u}{a}$ (``the finite element $u$ is a
member of the type-code $a$''). The characteristic clause for the identity type
is
\[
  \mem{\rEl(w)}{\cId(t,u,v)}
  \iff
  \mem{w}{t}\ \wedge\ w\le u\ \wedge\ w\le v ,
\]
i.e.\ a proof of $\cId(t,u,v)$ is exactly a witness of the underlying type that
lies \emph{below both endpoints} — the domain-theoretic reading of ``$u$ and
$v$ agree down to $w$''. All mismatched shapes (e.g.\ $\mem{\rEl(w)}{\Pi(\dots)}$
or $\mem{\cId(\dots)}{\Pi(\dots)}$) are empty, so identity codes and proof
values interact only with one another.

\medskip
\noindent
Evaluation relates a term $M$, an environment $\rho$, and a finite element
below its value; write $\ev{u}{M}$ for ``$u$ approximates $\sem{M}_\rho$''. The
new clauses (for $u\neq\bot$, where $\ev{\bot}{M}$ always holds) are
\begin{align*}
  \ev{\cId(t,u,v)}{\Id\,A\,a\,b}
    &\iff \ev{t}{A}\ \wedge\ \ev{u}{a}\ \wedge\ \ev{v}{b}, \\[2pt]
  \ev{\rEl(w)}{\Rf\,a}
    &\iff \ev{w}{a}, \\[2pt]
  \ev{c}{\Jelim\,C\,d\,p}
    &\iff \exists\,w.\ \ev{w}{p}\ \wedge\ \mathsf{br}(c,w),
    \quad\text{with}\quad
    \mathsf{br}(c,\rEl(w')) \iff \ev{\,\mathsf{fun}(w'\mapsto c)\,}{d}.
\end{align*}
So $\Id$ evaluates componentwise to an $\cId$-code, $\Rf$ to a proof value, and
$\Jelim\,C\,d\,p$ dispatches on the proof: once $p$ evaluates to a proof
$\rEl(w')$, the value of $\Jelim\,C\,d\,p$ is $\sem{d}$ applied to the witness
$w'$ (the single-edge condition ``$d$ maps $w'$ to $c$''). \textbf{The motive
$C$ does not occur in the value} — it constrains only the \emph{type}. This is
the based-J computation rule read in the model.

\section*{The logical relation and adequacy}

Adequacy is proved through a Kripke logical relation between the syntax and the
model. For each type it defines, at every finite element, when a term is
\emph{valid}; write $\valid{\Ga}{M}{A}{\mem{u}{a}}$ for ``$M$ is valid at type
$A$ and code $a$, with value $u$''. At an identity type the relation unfolds to:
\[
  \valid{\Ga}{M}{\Id\,A\,a\,b}{\mem{\rEl(w)}{\cId(t,u,v)}}
  \iff
  M \red \Rf\,w_0
  \ \text{for some } w_0 \text{ with }
  \cv{\Ga}{w_0}{a}{A}\ \text{and}\ \cv{\Ga}{w_0}{b}{A}\ \text{(both valid).}
\]
That is: a valid proof \emph{head-reduces to a canonical $\Rf\,w_0$} whose
witness $w_0$ is validly equal to both endpoints. (Because proofs are
proof-irrelevant, the underlying $\cId$-code carries no selection edge; the two
endpoint equalities are the whole content.)

\medskip
\noindent
\textbf{Adequacy.} By induction on derivations:
\[
  \ty{\Ga}{M}{A} \ \Longrightarrow\ M \text{ valid}, \qquad
  \cv{\Ga}{M}{N}{A} \ \Longrightarrow\ M,N \text{ validly equal.}
\]

\noindent
\emph{The $\Jelim$ case} (the based-J driver). Suppose $\ty{\Ga}{\Jelim\,C\,d\,p}
{C\,a\,b\,p}$ and let $c$ be a finite element below $\sem{\Jelim\,C\,d\,p}_\rho$.

\begin{enumerate}\itemsep2pt
\item By the evaluation clause, $c$ comes with a proof value: $p$ evaluates to
  some $\rEl(w')$ and $\mem{\rEl(w')}{\cId(t,u,v)}$, so $w'\le u$ and $w'\le v$.
\item The induction hypothesis for $p$ at $\Id\,A\,a\,b$ gives, via the relation
  above, a head reduction $p \red \Rf\,w_0$ with $w_0$ validly equal to $a$ and
  to $b$. Hence
  \[
    \Jelim\,C\,d\,p \ \red\ \Jelim\,C\,d\,(\Rf\,w_0) \ \redone\ d\,w_0
    \qquad\text{(J-scrut${}^*$ then J-$\beta$).}
  \]
\item \emph{$d$-edge.} The induction hypothesis for $d$ (a valid function),
  applied to the witness $w_0$, makes $d\,w_0$ valid at the diagonal type
  $C\,w_0\,w_0\,(\Rf\,w_0)$.
\item \emph{Type transport.} Using $\cv{\Ga}{w_0}{a}{A}$, $\cv{\Ga}{w_0}{b}{A}$
  and $\Rf\,w_0 = p$, the syntactic types are convertible,
  $\cv{\Ga}{C\,w_0\,w_0\,(\Rf\,w_0)}{C\,a\,b\,p}{\U}$; combined with
  monotonicity of the type-value along the information order, this carries the
  validity of $d\,w_0$ to the goal type $C\,a\,b\,p$.
\item \emph{Head expansion.} Finally, validity is stable under the head
  reduction $\Jelim\,C\,d\,p \red d\,w_0$ from step~2 (the contractum is valid,
  and the redex converts to it by J-$\beta$), so $\Jelim\,C\,d\,p$ is valid at
  $C\,a\,b\,p$. \hfill$\square$
\end{enumerate}

\noindent
The two-substitution (equality) version of this argument handles J-cong; it
splits the two witnesses coming from the two sides and bridges them with the
endpoint equalities.

\section*{Metatheorems (corollaries of adequacy)}

Both results are obtained by running adequacy at the \emph{bottom environment}
and reading the logical relation off the model.

\begin{theorem}[Id-injectivity, \texttt{ID/IdInjectivity.agda}]
If $\;\cv{\Ga}{\Id\,A_0\,a_0\,b_0}{\Id\,A_1\,a_1\,b_1}{\U}\;$ then
\[
  \cv{\Ga}{A_0}{A_1}{\U},\qquad
  \cv{\Ga}{a_0}{a_1}{A_0},\qquad
  \cv{\Ga}{b_0}{b_1}{A_0}.
\]
\end{theorem}

\noindent
Evaluate the given conversion at the bottom environment: it yields a validated
equality at the type-code $\cId(\bot,\bot,\bot)$, whose stored data are exactly
the component conversions between domain, left and right endpoints; a
head-reduction uniqueness lemma pins the codes, giving the three conversions.

\begin{theorem}[Subject reduction, \texttt{ID/SubjectReduction.agda}]
If $\;\ty{\Ga}{M}{A}\;$ and $\;M \redone N\;$ then $\;\ty{\Ga}{N}{A}$.
\end{theorem}

\noindent
For the \textsc{J-red} step the contractum $d\,a_0$ already has type
$C\,a_0\,a_0\,(\Rf\,a_0)$, retyped to the goal $C\,a\,b\,(\Rf\,a_0)$ using
$a_0=a$ and $a_0=b$ extracted from $\Rf\,a_0:\Id\,A\,a\,b$. For \textsc{J-scrut}
the result type $C\,a\,b\,p$ is transported along $p=p'$, obtained from
reduction-is-conversion; the $\Id$-typed proof needs only the diagonal
J-$\beta$, never $\Id$-injectivity. The $\beta$-step for functions inverts
$\lambda$-typing through $\Pi$-injectivity, as in the base theory.
